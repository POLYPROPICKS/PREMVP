## What this is — and is not

- **Population:** every supported (MONEYLINE / SPREADS / TOTALS / TOTAL_CORNERS) sibling captured at `T_MINUS_10` for events starting
  2026-10-01..2026-10-05: **6,342 siblings, 145 physical events** (MONEYLINE 870, SPREADS 2,880, TOTALS 2,592). All 145 events are
  `soccer` (frozen sport authority `research_evidence_page_rows.provider_sport_family`), so **C0, C1, C4 and C5 select identically** here;
  C1/C4/C5 add no information over C0 on this population.
- **Settlement:** the existing provider resolver (`resolveSignalOutcome`; Gamma list returned nothing for these conditions, so the resolver's
  CLOB fallback decided). 3,149 conditions looked up, 0 source-unavailable. States: SETTLED_WIN 3,083 · SETTLED_LOSS 3,083 · UNRESOLVED 176 ·
  no VOID / IDENTITY_NOT_PROVEN. Independent spot-check against the CLOB `tokens[].winner` flag: 12/12 agree. Unresolved is never a loss.
- **One common physical-event denominator: 141 events** (>= 1 settled, priced supported sibling), used by every model and view.
- **Frozen engine, unchanged:** `lib/modeling/research-engine` (C0 = 0.50 <= entry < 0.60; C1 adds soccer). One selected bet per physical event,
  chronologically first qualifying candidate; all siblings of an event share one T10 capture time, so ties resolve to the **lowest entry price**.
- **Three separate views (never merged):**
  - `RAW` — every sibling priced at its T10 best ask, ignoring the 0.54 cap, min order size and depth. **Not an executable return.**
  - `EXECUTABLE_UPPER_BOUND` — RAW minus siblings *conclusively* blocked at T10 (best ask above 0.54; $2.50 below the venue minimum at the best ask).
    Pre-telemetry rows never persisted the ask ladder (or, before 2026-10-03, the minimum order size), so depth / VWAP / fee are unknown: an upper bound.
  - `EXECUTABLE_PROVEN` — only rows whose `T10_EXECUTABLE_SIBLING_TELEMETRY_V1` state is EXECUTABLE: **0** (the telemetry is not released yet).

## Reading it honestly

1. **No positive edge is visible** in this window. Even the uncollapsed all-sibling view is negative (SPREADS weakest). The engine's lowest-price tie-break selected
   TOTALS 77 / MONEYLINE 38 / SPREADS 16 of the 131 events (independently replicated: 131 selections, 56W/75L). Sampling error is large (about +/-9 pp on N=131 for a
   flat-1u ROI), so this is "no evidence of an edge", not a proven negative.
2. **RAW overstates what is tradable.** 87 of the 131 RAW C0/C1 selections are conclusively not executable at T10 under the live invariants (above the 0.54 cap, or
   $2.50 under the venue minimum); only 44 remain in the upper bound, and none can yet be proven executable.
3. **Five days, soccer only, one capture per event.** Not enough to rank models; enough to size the executable gap and validate the pipeline.
4. Fee: 100% UNKNOWN (gross only) until telemetry rows exist.
